# Codex 用量宠物

使用本技能目录的 `scripts/main.py`，不要重新编写统计或余额逻辑。Windows 需要 Python 3.9+；优先使用可用的捆绑 Python，否则尝试 `py -3` 或 `python`。路径始终使用绝对路径并正确引用空格。

升级前先停止气泡，将 `.local` 的配置、加密凭证与余额缓存复制到插件缓存之外的本地备份，再执行安装。安装可能删除旧版缓存；不要在升级后才寻找旧版凭证，也不要打印或解密备份内容。恢复后使用新版本入口。

## 查看统计

运行 `main.py report`。脚本只输出面板路径和覆盖范围摘要，不输出密钥、会话正文或完整账单。将返回的绝对路径用以下内容引用放在最终回答中，让 Codex 显示交互面板：

`visualize{"path":"返回的绝对路径"}`

说明费用是按本地配置价格计算的估算，余额是平台账号范围。面板是本次查询的快照，用户说“更新用量”时再次执行报告；不要声称它实时自动刷新或显示在原生宠物旁。

首次没有配置也能查询 Token；余额显示未配置，费用未知不能当作零。如果客户端不支持内嵌内容引用，直接给出简洁数字报告并说明面板显示限制。

## 配置平台和价格

先运行 `main.py init`，它创建插件目录内 `.local/config.local.json`，不覆盖已有配置。阅读 `references/configuration.md` 后，仅编辑其中的平台、接口元数据、模型价格和时间设置。余额接口依据公开文档、用户提供说明或已有可靠实现配置，不猜测接口。

密钥不能写入配置、对话、命令参数或日志。用户需要配置余额令牌时，运行 `main.py set-secret --platform 平台ID`，让用户在本地密码输入窗口填写。窗口由插件命令启动，脚本只报告保存／取消，令牌使用当前 Windows 用户的 DPAPI 加密。如果无法显示本地窗口，告知具体阻塞，不通过聊天索取完整令牌。

只有用户确认的 Codex provider 与平台映射才写入 `providers`；不根据模型名或账号消费猜测平台。价格不明时保留空配置，展示未知。

## 桌面余额气泡

用户说“开启宠物余额气泡”时运行 `main.py bubble-start`；说“关闭气泡”时运行 `main.py bubble-stop`；状态用 `main.py bubble-status`。所有命令使用同一配置绝对路径，避免控制错配置实例。脚本启动 pythonw 后返回，用户不用打开 EXE。不要用任务管理器终止所有 Python 或 Codex 进程。

默认 `bubble.display` 为 `click`：启动后气泡隐藏，点击原生角色并松开鼠标后显示 5 秒，再自动隐藏。再次点击重置 5 秒；拖动和长按不弹出。隐藏不会结束进程，仍可等待下一次点击。`running: true` 只证明进程已启动；点击模式中 `visible: false` 属于正常等待。检查 `display`、`mode` 与 `location` 确认状态，不为了让它常驻改成演示。

点击识别使用 Windows 鼠标事件，不吞掉事件、不改变原生点击行为、不记录鼠标轨迹。找不到原生宠物时隐藏气泡，打开宠物后继续等待。自动跟随读取 Codex 保存的位置，拖动结束后更新，不能声称实时逐帧跟随。

用户要求手动摆放时运行 `main.py bubble-start --manual`；已有实例需先停止再启动，或使用气泡右键菜单切换。手动模式下拖动气泡即可保存位置。右键菜单可切换平台、恢复跟随和关闭。演示使用 `--bubble-demo --manual`，必须说明是模拟数字，不能当作真实余额。

气泡请求至少间隔 60 秒，无手动刷新按钮；点击模式先预取一次，点击后立即显示最近数据，达到刷新间隔时后台更新。完整图表仍用 `report` 在 Codex 中显示。余额令牌和价格未配置时显示横线，不为了填满数字读取旧版账号配置。不同配置目录可能产生多个实例，应沿用同一配置。

气泡今日 Token 为本机所有 Codex 桌面端今日用量，与选择哪个余额平台无关。今日估算仍需要所选平台的 provider 映射和模型价格；缺少时显示“未配置价格”，不能用账号全部消费代替 Codex 费用。底部“更新”是余额成功时间，按配置时区显示。

用户明确要求显示中转站账号今日实际消费时，按配置指南设置 `bubble.cost_source: "platform"`，再重新开启气泡。当前仅支持已核实的企鹅 `/api/data/self` 接口。气泡标为“今日消费”，不依赖模型价格，范围包含其他软件。Token 与模型图表仍属于 Codex，不能把账号消费称为 Codex 专属费用。报告中账号卡片也显示实际今日消费。

气泡是独立透明窗口，由插件控制；没有修改原生宠物，也不假装是 Codex 开放的原生气泡接口。Windows GUI 启动若需要当前工具权限，按实际权限流程执行；不要在无桌面隔离环境中声称已显示。

## 原生宠物

角色使用用户已通过 hatch-pet 创建的宠物，或 Codex 已有角色。用户说开启／切换宠物时引导其在 Codex 的宠物设置中选择；不伪造宠物控制工具、不修改应用内部资源、不要求手动启动 EXE。

插件安装、配置和本地余额请求不会产生模型调用；让 Codex 执行技能本身仍可能使用 Token。统计只能覆盖本机保留且能确认来源的会话，不能声称是账号终身用量。
