# 本地配置

配置文件由 `scripts/main.py init` 创建，默认在已安装插件根目录 `.local/config.local.json`，不是源码下载目录。升级插件前保留此目录，或通过脚本 `--config 绝对路径` 指定持久配置位置；所有报告、凭证和气泡控制命令都必须沿用该路径。配置没有明文密钥。

**升级前先关闭气泡，再复制 `.local` 中的配置、加密令牌及余额／今日消费缓存到插件缓存之外的本地备份，最后运行安装命令。** 本机实测 `codex plugin add` 更新版本会清理旧缓存，不能等安装后才迁移。只恢复配置、凭证和必要缓存，不恢复锁文件、进程状态和停止信号。备份不得放入发布包或 GitHub。

```json
{
  "timezone_offset": "+08:00",
  "providers": {"用户确认的Codex-provider-ID": "relay-a"},
  "platforms": [
    {
      "id": "relay-a",
      "name": "我的中转站",
      "balance": {
        "adapter": "json_get",
        "url": "https://example.invalid/按真实文档填写",
        "documentation_url": "https://example.invalid/接口说明",
        "field": ["data", "balance"],
        "unit": "按文档填写",
        "divisor": "1",
        "headers": {},
        "auth": {"header": "Authorization", "prefix": "Bearer "}
      },
      "prices": {
        "文档中的模型名": {
          "unit": "USD",
          "input": "按文档填写每百万输入价格",
          "cached_input": "按文档填写每百万缓存读取价格",
          "output": "按文档填写每百万输出价格"
        }
      }
    }
  ]
}
```

上述域名、字段、认证与价格只是结构示例，不是任意中转站的接口约定。`init` 创建的是空平台列表，不会请求示例域名。

`json_get` 仅允许 HTTPS GET。`field` 是明确的对象字段／数组索引路径。返回原始值除以 `divisor`；默认 1，只有真实文档规定换算时修改。可选 `success_field` 与 `success_value` 用于验证成功标志。`headers` 只能填写非敏感元数据，如用户 ID；认证值由本地加密令牌提供。

`auth` 可省略以访问公开接口；私有接口按真实文档设置认证头和前缀。凭证禁止放在 URL、headers 或价格配置内。请求不跟随重定向，避免向新地址转发认证。

已验证企鹅 API 的适配器名为 `penguin`：只支持 `https://penguinapi.org`，使用 `/api/user/self` 获取 quota，`/api/status` 获取显示与换算规则。需要平台账号访问令牌，而不是假定模型调用 Key 可通用；可选 `user_id`。其账号 used_quota 不用于 Codex 费用统计。其他 New API 站点需独立确认文档，不能仅凭相似外观启用企鹅适配器。

价格单位是每百万 Token。缓存读取从输入总量扣除后按缓存价计算；推理输出已经在输出总量中，不重复收费。若记录有缓存写入，需要配置 `cache_write_input` 价格和 `cache_write_in_input`（true 或 false）以明确平台计费口径。非零 Token 对应价格缺失时，该调用费用为未知；不把部分调用价格当作完整费用。

一个 provider 只能映射到一个明确的平台；同一 provider 历史上切换过平台时，当前简单映射会影响全部历史。此时不要映射，或使用独立 provider ID。多个模型／平台不同币种不相加。

Codex 模型费用均为本地价格估算，未接入可归属到 Codex 各请求的真实账单。可选的账号今日实际消费是另一项统计，目前仅支持企鹅 API，范围包含其他软件调用；它不替代模型图表的估算。其他平台的余额可按上述 json_get 配置，但账号消费需要新增源码适配，不能只改网址或开启 cost_source。

## 桌面气泡

`cost_source` 可设为 `"estimate"`（默认）或 `"platform"`。后者显示所选平台账号今日实际消费，不再按模型价格估算；Token 仍只统计 Codex。目前实际消费仅核实企鹅 API，读取 `GET /api/data/self`，按配置时区当天零点至查询时间汇总 `quota`，用 `/api/status` 的规则展示。该费用包含其他软件调用，与 Codex 专属用量不同。其他平台需先核实其今日账单接口，不能猜测。

今日消费按日独立缓存、请求至少相隔 60 秒；失败保留当日旧数据并标为旧，不把昨天的费用带到今天，也不以余额差推算消费。统计面板的账号卡片显示实际今日消费，模型图表仍明确为 Codex 用量／费用估算，不把全账号消费分摊给本地模型。

默认 `display` 为 `"click"`：点击原生角色后弹出 5 秒，再次点击重新计时；拖动和长按不触发。到时只是隐藏，进程继续等待点击。设置 `"always"` 可恢复常驻显示；更改显示方式后建议关闭再开启。点击检测区域是已保存的角色矩形，并验证按下时鼠标实际命中原生宠物窗口，因此人物边缘可能也会触发。原生点击仍会正常传递，不关闭 Codex 自己弹出的菜单或通知。

点击模式预取一次数据；以后弹出先用最近数据，间隔达到 60 秒时后台刷新。等待点击期间不定时发余额请求，也不强制将未完成请求取消。单位和原成功时间可通过气泡右键详情查看。

可在顶层增加 `bubble` 对象：`refresh_seconds` 为 60–3600 的整数秒数（默认 60），`platform_id` 为要显示的平台 ID。右键切换平台和拖动气泡会保存 `manual` 与 `position`；不要手工写入敏感信息。

`manual` 只能为布尔值，`position` 为两个有限屏幕坐标（允许负坐标），`platform_id` 必须对应已配置平台。有效的配置更改在下一次成功刷新后应用；修改不合法时保留旧数据并提示异常。`--manual` 用于本次启动的初始模式，之后仍可通过菜单或配置修改。

默认跟随模式只读 Codex 的宠物开启状态和已保存的坐标；拖动原生宠物结束后更新。此定位方式依赖 Codex 当前版本，不是公开宠物扩展接口。找不到明确坐标时隐藏气泡，不自动绑到 Codex 主窗口。使用 `bubble-start --manual` 或右键切为手动摆放可解除跟随。

同一配置目录只能运行一个气泡；控制命令需使用一致的 `--config` 路径。切换认证令牌会清除该平台旧余额和消费缓存。气泡有自己的后台刷新，不需要创建定时 Codex 对话或自动化。
